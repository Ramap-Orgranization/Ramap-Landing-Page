# Ramap Landing Page

대한민국 라멘 지도, 라맵을 소개하는 React + TypeScript + Vite 정적 랜딩 페이지입니다.

## 실행

```bash
npm ci
npm run dev
```

배포용 빌드는 다음 명령으로 확인합니다.

```bash
npm run build
npm run preview -- --host 127.0.0.1 --port 4173
```

정적 산출물은 `dist`에 생성됩니다. Vercel 또는 정적 호스팅에서 별도 서버 없이 배포할 수 있습니다.
